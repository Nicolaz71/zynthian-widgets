# Changelog — Ultramaster KR-106 UI

## v0.5.2 — 2026-11-24

- **UP/DOWN** now changes pages without pressing ALT.
- **LEFT/RIGHT** now changes parameter groups without pressing ALT.
- Cyclic navigation, rotary encoders, touch controls, Z/MIDI Learn and responsive header preserved.
- Hardware-tested on Zynthian Tomita with the original KR-106 synthesizer.
- Pure LV2 widget update; no DSP changes.


## v0.5.1 — 2026-11-23

- Initial public release of the widget for the **original** KR-106 LV2 plugin.
- Four touchscreen pages, 20 encoder groups and 56 controller slots.
- Tomita LV2 widget-only extension: no audio engine included.
- Header-fit fix: ULTRAMASTER/KR-106 adapt to narrow Touch Navigation layouts.
- Display label is GUI 0.5.1 (without the leading v), located next to Z.
- Widget has been tried successfully with the original engine on Zynthian Tomita.

The internal source revision packaged here is `0.5.1-tomita-original-r2`.
